## One message per slide

Each slide carries one message: its assertion title and the visual evidence for
it. Working memory holds about three to four chunks at once, so split a slide
that needs more. Mayer's multimedia principles give the reasons:

- Words with pictures teach better than words alone.
- Graphics with narration teach better than graphics with narration and the
  same words on screen (redundancy).
- Extra elements interfere with learning (coherence).

## Typography

| Element | Default |
| --- | --- |
| Minimum font size | 24 pt; 28 pt in a large room or with poor projection |
| Font family | Sans-serif, such as Arial, Helvetica, or Calibri |
| Contrast | Dark text on a light background |

Show only content that the audience can read from the farthest seat.

## Text density

| Element | Maximum |
| --- | --- |
| Text lines per slide | 9; 6 or fewer is better |
| Bullets per slide | 5 |
| Lines per bullet | 2 |
| Words per bullet | 10 |

Audiences read faster than speakers talk, so slide text that repeats the
speech competes with it. Replace text with visual evidence where possible.

## Visual evidence

- Show one visual message per slide.
- Prefer one large, simple figure to a multi-panel figure.
- Remove decoration: clip art, background patterns, shadows, gradients, 3D
  effects, and gridlines that no reading of a value needs.
- Annotate directly: put arrows and labels at the feature that matters.

## Adapting published figures

A reader controls how long they study a journal figure; an audience gets a few
seconds. To adapt a figure:

1. Name the point that the figure supports.
2. Keep only the panels and data series that show that point.
3. Enlarge the labels to the minimum font size.
4. Annotate the feature that carries the point.
5. Redraw the figure when simplifying is not enough.

Then give it its source, purpose, and marker definitions (see
[Figures and schematics](slide-text.md#figures-and-schematics)).

## Graphs and tables

- Show trends as line graphs, relationships as scatter plots, group
  comparisons as bar charts, and distributions as histograms or box plots.
- Use a table only when the audience needs exact values, and keep it small.
- Choose scales and graph types that represent the data faithfully. Replace
  software defaults that serve no purpose.

## Equations

- Show an equation only when the talk explains it. In a short talk, show few.
- Decompose a complex equation: discuss each term while the other terms are
  greyed out.
- Pair each equation with a plain-language statement and, where it helps, a
  plot of its behaviour.
- Define every symbol, on screen and in speech.
- Typeset equations with LaTeX or the template's equation tool, at full
  resolution.

# Triage labels

Use this mapping when a development skill names a canonical triage role.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | A maintainer needs to evaluate the issue. |
| Needs information | `needs-info` | More information is needed from the reporter. |
| Ready for an agent | `ready-for-agent` | The work is specified enough for an agent to implement. |
| Ready for a human | `ready-for-human` | The work requires human implementation. |
| Will not fix | `wontfix` | The issue will not be actioned. |

This table defines the intended vocabulary, not an inventory of labels
already created on GitHub. Inspect `gh label list` before applying a label.
Create a missing mapped label as part of an authorized triage task; keep
unrelated labels intact.

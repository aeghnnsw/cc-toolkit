### Changed

- dev-skills (Claude Code 3.88.0, Codex 1.74.0, Antigravity 1.43.0): in t3-project-lead, a T3 Code build names the check parameter of `pull_request_read` `include`, so the hook blocked every check read of a lead in that build. The hook now passes `sections` or `include` set to `["checks"]`, and blocks a call with neither, with any other value, or with two different values. It also blocks `t3_thread_read` without `maxCharsPerItem`, and `start` names `maxCharsPerItem 8000` (#638). See [#632](https://github.com/aeghnnsw/cc-toolkit/issues/632).
- Repository: ADR 0008 records both rules, and the t3-project-lead tests and scenario record check them (#638). See [#632](https://github.com/aeghnnsw/cc-toolkit/issues/632).

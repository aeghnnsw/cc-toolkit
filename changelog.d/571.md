### Changed

- dev-skills (Claude Code 3.73.0, Codex 1.60.0, Antigravity 1.28.0): `run_suite.py` reads a priority marker, `run-suite-priority.json` in the Git common folder, that a repository's merge-lock tool writes. While a fresh marker names another worktree, each run waits and holds no suite lock while it waits, and the summary reports the wait. In matt-automode 1.25.0, the Sub-agent briefs name this wait. See [#571](https://github.com/aeghnnsw/cc-toolkit/issues/571).
- Repository: ADR 0011 records the priority marker contract of `run_suite.py`, and the glossary defines "Suite lock" and "Priority marker". See [#571](https://github.com/aeghnnsw/cc-toolkit/issues/571).

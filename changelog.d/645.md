### Changed

- dev-skills (Claude Code 3.90.0, Codex 1.76.0, Antigravity 1.45.0): in t3-project-lead, only the user settles the lead thread. `finish` and the `report` step now tell the lead to leave its thread open, and `start` and each skill copy state the rule. In a recorded lead session, the hook blocks `t3_thread_organize` with `action` `settle` when the call names no `threadId`, the calling thread, or the owner of the lead state, and fails closed when it cannot tell. A settle of a worker's thread does not change. See [#645](https://github.com/aeghnnsw/cc-toolkit/issues/645).
- Repository: ADR 0008, the glossary entry "Settle", and `README.md` record the rule, and the t3-project-lead tests and scenarios check it. See [#645](https://github.com/aeghnnsw/cc-toolkit/issues/645).

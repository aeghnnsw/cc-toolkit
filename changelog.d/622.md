### Changed

- core-hooks (Claude Code, Codex, and Antigravity 1.2.1): when `zsh_traps.py` denies a command for an unquoted `=word` that names no command, the denial ends with the whole corrected command, which the agent can run as it is. The corrected command has a backslash before the `=` of each such word, as in `echo \=====; ls`, and no other change. The denial gives no corrected command for a command with a heredoc or with more than 1500 characters, or when the hook blocks the corrected command too. See [#622](https://github.com/aeghnnsw/cc-toolkit/issues/622).

### Added

- core-hooks (Claude Code, Codex, and Antigravity 1.1.0): zsh_traps warns about GNU options that the BSD tools of macOS reject (`head -n 0`; `cat -A`, `-E`, `-T`, or a long option), and about `timeout` when no `timeout` command is on `PATH`. Antigravity skips these warnings, because an Antigravity hook cannot warn without blocking. See [#457](https://github.com/aeghnnsw/cc-toolkit/issues/457).
- Repository: root tests check the 78-column prose width of `CLAUDE.md` and `CONTRIBUTING.md`, the README skill lists and the Codex `longDescription` phrases, each shell block of a shipped Markdown file in bash and zsh with the zsh trap check, the `mktemp` form, the Python floor of plugin scripts and the commands that run them, and each `<plugin>:<name>` reference. The project-eval Set Up block runs in bash and zsh in the Dev Skills tests. See [#457](https://github.com/aeghnnsw/cc-toolkit/issues/457).

### Changed

- productivity-skills (Claude Code and Codex 7.10.0, Antigravity 1.4.0): `gtd_sql.py` declares `requires-python = ">=3.11"` in PEP 723 inline script metadata, so the Python floor check covers each command that runs it. See [#457](https://github.com/aeghnnsw/cc-toolkit/issues/457).

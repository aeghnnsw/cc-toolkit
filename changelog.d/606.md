### Changed

- dev-skills (Claude Code 3.95.0, Codex 1.81.0, Antigravity 1.50.0): in t3-project-lead, the lead pins each worker until its task is verified or cancelled, because T3 settles a waiting worker by itself. The lists print each worker as a link that T3 opens. The hook also blocks a lead's archive of its own thread. `task pr --package` keeps a merge order, so that parallel PRs of one plugin do not each rebase after every merge (#659, #660, #668, #669). See [#606](https://github.com/aeghnnsw/cc-toolkit/issues/606).
- Repository: CONTRIBUTING gives the rebase rule for conflicts that only add independent notes, and the merge order of parallel PRs of one plugin. The glossary and ADR 0008 record the pin, link, archive, and merge-order rules of t3-project-lead (#659, #660, #668, #669). See [#606](https://github.com/aeghnnsw/cc-toolkit/issues/606).

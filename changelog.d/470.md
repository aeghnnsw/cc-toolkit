- dev-skills (Claude Code 3.79.0, Codex 1.65.0, Antigravity 1.34.0): sci-project-layout 1.2.0 ships a Set up script, `scripts/set_up.py`. It copies the templates, adds the missing `.gitignore` lines, and replaces `myproj` and `MYPROJ`, and it never overwrites a file. Set up ends with the script output, a `git grep` for `myproj`, `git status`, and the import check. The templates name no cc-toolkit skill, and `layout.md` names `CLAUDE.md`, `AGENTS.md`, or `GEMINI.md`. See [#470](https://github.com/aeghnnsw/cc-toolkit/issues/470).

### Changed

- dev-skills (Claude Code 3.93.0, Codex 1.79.0, Antigravity 1.48.0): in t3-project-lead, the hook records a session as the lead only at `init`, at `takeover`, and at a `start` of the thread that owns the lead state, and fails closed when it cannot tell the owner. The new `unmark` command removes a wrong record from a thread that is not the lead. A recorded session may also read the tool outputs that Claude Code saved for it, and its gtd-inbox files (#621). See [#612](https://github.com/aeghnnsw/cc-toolkit/issues/612).
- Repository: ADR 0007 and ADR 0008 record the new rules, and the t3-project-lead tests and scenarios check them (#621). See [#612](https://github.com/aeghnnsw/cc-toolkit/issues/612).

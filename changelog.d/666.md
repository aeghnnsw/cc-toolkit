### Changed

- dev-skills (Claude Code 3.94.0, Codex 1.80.0, Antigravity 1.49.0): in t3-project-lead, a lead works only in its own project. The skill and the `start`, `discover`, `brief`, `verify`, `closeout`, and `report` steps say that, for work of another project, the lead only reports to that project's lead or has a worker file an issue there, and never lists or offers that work. In Claude Code and Codex, the hook blocks the T3 calls that name another project, all projects, or a Scratch folder. See [#666](https://github.com/aeghnnsw/cc-toolkit/issues/666).
- Repository: the glossary and ADR 0008 record the project rule of t3-project-lead, and its tests and scenarios check it. See [#666](https://github.com/aeghnnsw/cc-toolkit/issues/666).

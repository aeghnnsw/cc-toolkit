### Changed

- dev-skills (Claude Code 3.89.0, Codex 1.75.0, Antigravity 1.44.0): `git branch -D` exits 0 also when it cannot write the Git config, as in a sandbox, and leaves the section `branch.<name>`. The repo-cleanup plan now prints a `REMOVE config-section branch.<name>` line for each such section whose local branch does not exist. A new `--config-sections` option prints only these lines. repo-cleanup runs it after the branch step, removes each section with `git config --remove-section`, and reports the error when the config is read-only. See [#643](https://github.com/aeghnnsw/cc-toolkit/issues/643).

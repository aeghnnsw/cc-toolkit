### Changed

- dev-skills (Claude Code 3.82.1, Codex 1.68.1, Antigravity 1.37.1): in t3-project-lead, the T3 Code tool `pull_request_read` takes `sections`, not `include`, so the hook passed `sections: ["conversation", "diff"]`. The hook now passes `pull_request_read` only when `sections` is exactly `["checks"]` and any `include` is `["checks"]` too; a call without `sections` blocks. `start` names `sections` and says that a worker sets triage labels. See [#604](https://github.com/aeghnnsw/cc-toolkit/issues/604).
- Repository: ADR 0008 records the `sections` rule. The t3-project-lead tests check it in the Claude Code and Codex tool names, and the new `start` lines. See [#604](https://github.com/aeghnnsw/cc-toolkit/issues/604).

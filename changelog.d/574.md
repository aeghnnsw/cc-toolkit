It records nothing when it cannot resolve the script path. See [#574](https://github.com/aeghnnsw/cc-toolkit/issues/574).
- Repository: ADR 0007 and ADR 0008 record the `start` rule for a command list. See [#574](https://github.com/aeghnnsw/cc-toolkit/issues/574).

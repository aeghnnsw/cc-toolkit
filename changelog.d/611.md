### Changed

- dev-skills (Claude Code 3.92.0, Codex 1.78.0, Antigravity 1.47.0): in t3-project-lead, `task -h` and `decision -h` list each action. `decision start <N>` continues the user's decision numbers, and `decision add` refuses a `D<n>` label that is not the next ID. `task add --kind closeout` refuses a batch with an open task. A batch close-out deletes merged work without asking and removes the worktrees of its verified tasks. `wait --answer-in` lists a yes for a worker's thread in its own section (#613, #614, #639, #642, #644). See [#611](https://github.com/aeghnnsw/cc-toolkit/issues/611).
- Repository: ADR 0008 records that a batch close-out removes the worktrees of its verified tasks, and that a yes for a worker's protected step waits in the worker's thread. The glossary, the t3-project-lead scenarios, and the tests cover the changes (#613, #614, #639, #642, #644). See [#611](https://github.com/aeghnnsw/cc-toolkit/issues/611).

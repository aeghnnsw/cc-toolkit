### Changed

- dev-skills (Claude Code 3.89.1, Codex 1.75.1, Antigravity 1.44.1): when the priority marker that a `run_suite.py` run waits for is gone, the run waits up to 15 s for the marker of the next merge-lock holder before it takes the suite lock. Before, a run of a third worktree that waited for the marker took the suite lock while the merge lock passed from one worktree to the next. Then the new merge-lock holder waited for that run. See [#641](https://github.com/aeghnnsw/cc-toolkit/issues/641).
- Repository: ADR 0011 records the handover wait. See [#641](https://github.com/aeghnnsw/cc-toolkit/issues/641).

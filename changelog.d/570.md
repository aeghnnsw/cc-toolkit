### Changed

- Repository: a pull request that closes several issues adds one entry file, named by its lowest issue number. Each bullet names the other issues inline as bare numbers without a link, as in `(#555, #556)`, and links the lowest issue. The package validator fails a branch that adds more than one new bullet for a plugin or more than one new `Repository:` bullet, and its errors show the form for several issues. See [#570](https://github.com/aeghnnsw/cc-toolkit/issues/570).

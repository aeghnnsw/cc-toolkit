### Changed

- dev-skills (Claude Code 3.83.0, Codex 1.69.0, Antigravity 1.38.0): in repo-cleanup 1.13.0, session logs and Antigravity conversations do not keep a worktree whose path a lead task records in an accepted state (`verified`, `closed-out`, or `settled`, and not cancelled); a Git lock or a running process still keeps it. `live_worktrees.py` prints the time when the 60-minute window ends, and the plan reason gives it. repo-cleanup runs the plan once more after that time and does not ask the user. See [#610](https://github.com/aeghnnsw/cc-toolkit/issues/610).
- Repository: ADR 0008 records the rule for the session logs of an accepted task. See [#610](https://github.com/aeghnnsw/cc-toolkit/issues/610).

### Changed

- dev-skills (Claude Code 3.83.0, Codex 1.69.0, Antigravity 1.38.0): in repo-cleanup 1.13.0, session logs and Antigravity conversations do not keep a worktree when each lead task that records it is accepted (`verified`, `closed-out`, or `settled`, and not cancelled). The rule for a task that is not `settled` decides first, so this frees the worktree of a `settled` task. A Git lock or a running process still keeps it. The plan reason gives the end of the 60-minute window, and repo-cleanup runs the plan again after it without asking. See [#610](https://github.com/aeghnnsw/cc-toolkit/issues/610).
- Repository: ADR 0008 records the rule for the session logs of an accepted task. See [#610](https://github.com/aeghnnsw/cc-toolkit/issues/610).

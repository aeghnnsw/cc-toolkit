### Changed

- dev-skills (Claude Code 3.76.0, Codex 1.62.0, Antigravity 1.31.0): in repo-cleanup 1.12.0, `cleanup_plan.py` reads the T3 Code threads of the repository with the `t3` CLI and keeps each worktree that a thread owns while the thread is not `settled`. Without the CLI, or for a repository that is no T3 Code project, the other rules decide. When the CLI fails, for example while the T3 Code app is closed, it keeps every worktree that it would otherwise remove. See [#578](https://github.com/aeghnnsw/cc-toolkit/issues/578).

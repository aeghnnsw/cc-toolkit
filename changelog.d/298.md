### Added

- Repository: a pull request adds its changelog bullets in an entry file, `changelog.d/<N>.md`, not in `CHANGELOG.md`. The package validator checks them and fails a new bullet in `CHANGELOG.md`. `scripts/release_changelog.py`, the release step, moves the entry files into `CHANGELOG.md` in a pull request of its own. `scripts/next_versions.py` sets the next free versions above `origin/master` and writes them into the entry files. ADR 0010 records the decision. See [#298](https://github.com/aeghnnsw/cc-toolkit/issues/298).

### Changed

- dev-skills (Claude Code 3.72.0, Codex 1.59.0, Antigravity 1.27.0): in matt-automode 1.24.0, a rebase runs the repository's version script when it has one. When CI runs the suites, and the resolution changes only versions and changelog entries, only the version and changelog checks run again locally. See [#298](https://github.com/aeghnnsw/cc-toolkit/issues/298).
